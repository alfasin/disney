## Project Overview

This is a React example app demonstrating PGlite (Postgres in WASM) with its React hooks integration. It lives inside the `pglite` monorepo at `examples/react/` but uses published npm packages, not local workspace packages.

## Commands

```bash
# Install deps (use --ignore-workspace to avoid installing full monorepo)
pnpm i --ignore-workspace

# Dev server
pnpm dev

# Build (TypeScript check + Vite build)
pnpm build

# Lint
pnpm lint
```

## Architecture

**Stack:** Vite + React 19 + TypeScript, using `@electric-sql/pglite` and `@electric-sql/pglite-react`.

**Key files:**
- `src/App.tsx` — Creates the PGlite instance with the `live` extension in a `useEffect`, wraps children in `PGliteProvider`. Uses a module-level variable (`dbGlobal`) to prevent re-initialization under React strict mode.
- `src/MyPGliteComponent.tsx` — Uses `usePGlite()` hook to get the db instance and insert rows.
- `src/MyPGliteItemsComponent.tsx` — Uses `useLiveQuery()` to reactively display the 5 most recent rows.

**PGlite React API pattern:**
1. `PGliteProvider` wraps the component tree with the db instance
2. `usePGlite()` retrieves the db instance from context
3. `useLiveQuery()` subscribes to query results that auto-update on data changes

**Vite config:** `@electric-sql/pglite` must be excluded from Vite's dependency optimization (`optimizeDeps.exclude`) because it contains WASM.

## Monorepo Context

This example is part of the `electric-sql/pglite` pnpm monorepo. The root repo uses pnpm 9+ and Node 20+. Key monorepo packages are under `packages/` (pglite, pglite-react, pglite-vue, pglite-sync, etc.). PRs to the monorepo require running `pnpm changeset` at the root.
